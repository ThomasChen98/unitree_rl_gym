# 新版拳击动作说明

## 动作特点
新的 `boxing` 轨迹采用了更真实的拳击节奏：

### 时间安排
- **总周期**: 4秒
- **左拳阶段**: 0-2秒
  - 0.0-0.5秒: 快速出拳
  - 0.5-2.0秒: 保持出拳姿态（停顿1.5秒）
- **右拳阶段**: 2-4秒  
  - 2.0-2.5秒: 快速出拳
  - 2.5-4.0秒: 保持出拳姿态（停顿1.5秒）

### 动作效果
1. **力量感**: 出拳后的停顿展现了力量的持续性
2. **节奏感**: 明确的时间节拍，类似真实拳击训练
3. **控制精度**: 展示机器人精确的姿态保持能力
4. **视觉冲击**: 停顿让观察者有时间欣赏完整的拳击姿态

### 关节角度设置
```python
punch_extension = -3.0   # 出拳时前伸角度
guard_position = 0.1     # 防守时手臂位置  
elbow_bend_punch = -0.8  # 出拳时肘部角度
elbow_bend_guard = -1.5  # 防守时肘部弯曲
```

### 测试命令

### 观察要点
- 注意左右拳的交替出击
- 观察出拳后的停顿效果
- 感受动作的力量感和节奏感
- 验证机器人的姿态保持能力

这种设计让拳击动作更加逼真，同时展示了机器人在复杂时序控制方面的能力。
