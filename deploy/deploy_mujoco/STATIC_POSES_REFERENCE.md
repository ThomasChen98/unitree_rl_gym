# H1_2机器人静止上身动作参考

本文档详细描述了H1_2机器人混合控制系统中可用的静止上身动作。

## 静止动作概述

静止动作是指机器人上身保持固定姿态，不进行连续运动的动作模式。这些动作适用于需要机器人保持特定姿态的应用场景。

## 可用的静止动作

### 1. 基础静止动作（原有）

#### arms_forward - 双臂前伸
- **描述**: 双臂水平向前伸展
- **应用**: 递接物品、指示方向
- **关键参数**: 肩膀前伸约0.8弧度

#### left_down_right_forward - 左下右前
- **描述**: 左臂自然下垂，右臂向前伸展
- **应用**: 单手指示、不对称操作准备
- **关键参数**: 仅右臂前伸

#### arms_cross - 十字架姿态
- **描述**: 双臂水平张开，呈十字形
- **应用**: 展示、平衡训练
- **关键参数**: 双臂外展约90度

#### left_down_right_side - 左下右侧
- **描述**: 左臂下垂，右臂侧向张开
- **应用**: 单侧展示、非对称姿态
- **关键参数**: 右臂侧向外展

#### torso_forward - 躯干前倾
- **描述**: 躯干向前倾斜
- **应用**: 鞠躬动作、前倾姿态
- **关键参数**: 躯干前倾约30度

#### torso_left - 躯干左倾
- **描述**: 躯干向左倾斜
- **应用**: 侧向动作、平衡练习
- **关键参数**: 通过手臂姿态表现左倾

#### torso_side - 躯干侧扭
- **描述**: 躯干侧向扭转
- **应用**: 扭转动作、灵活性展示
- **关键参数**: 不对称手臂配置

#### left_up_right_down - 左上右下
- **描述**: 左臂上举，右臂下垂
- **应用**: 不对称姿态、挥手准备
- **关键参数**: 左臂向上，右臂自然下垂

### 2. 新增静止动作

#### pose_arms_forward - 双臂前伸（新版本）
- **描述**: 优化的双臂前伸动作
- **特点**: 更精确的关节角度控制
- **关键参数**: 肩膀前伸0.8弧度，肘部伸直

#### pose_left_down_right_forward - 左下右前（新版本）
- **描述**: 改进的左下右前动作
- **特点**: 更自然的姿态过渡
- **关键参数**: 左臂完全放松，右臂精确前伸

#### pose_t_shape - T形姿态
- **描述**: 完美的十字架形状
- **特点**: 精确的90度角度控制
- **关键参数**: 双臂完全水平张开，肩膀外展1.2弧度

#### pose_left_down_right_side - 左下右侧（新版本）
- **描述**: 优化的左下右侧动作
- **特点**: 更稳定的单侧展开
- **关键参数**: 右臂精确侧向外展1.2弧度

#### pose_torso_forward_twist - 躯干前扭
- **描述**: 躯干向前扭转动作
- **特点**: 主要绕Y轴旋转
- **关键参数**: 躯干前倾0.5弧度

#### pose_torso_left_twist - 躯干左扭
- **描述**: 躯干向左扭转动作
- **特点**: 通过手臂不对称表现扭转
- **关键参数**: 左臂稍上举，右臂稍下垂

#### pose_torso_side_twist - 躯干侧扭（新版本）
- **描述**: 改进的躯干侧向扭转
- **特点**: 更明显的扭转效果
- **关键参数**: 左臂向右前方，右臂向左后方

#### pose_left_up_right_down - 左上右下（新版本）
- **描述**: 优化的左上右下动作
- **特点**: 更自然的上举动作
- **关键参数**: 左臂后伸上举-0.8弧度

## 使用方法

### 命令行调用
```bash
# 基础动作
python deploy_mujoco3.py h1_2_hybrid.yaml --trajectory arms_forward
python deploy_mujoco3.py h1_2_hybrid.yaml --trajectory left_down_right_forward

# 新增动作
python deploy_mujoco3.py h1_2_hybrid.yaml --trajectory pose_t_shape
python deploy_mujoco3.py h1_2_hybrid.yaml --trajectory pose_torso_forward_twist
```

### 批量演示
```bash
# 运行完整演示（包含所有静止动作）
./demo_complete.sh

# 仅演示静止动作
for pose in arms_forward pose_t_shape pose_left_up_right_down; do
    python deploy_mujoco3.py h1_2_hybrid.yaml --trajectory $pose
done
```

## 关节角度参考

### 上身关节索引（15个关节）
```
0:  躯干旋转
1-7:  左臂（肩膀x3 + 肘部x1 + 手腕x3）
8-14: 右臂（肩膀x3 + 肘部x1 + 手腕x3）
```

### 典型角度范围
- **肩膀前后伸**: -1.5 ~ 1.5 弧度
- **肩膀外展**: -2.0 ~ 2.0 弧度
- **肘部弯曲**: 0 ~ 2.5 弧度
- **躯干旋转**: -1.0 ~ 1.0 弧度

## 自定义静止动作

要创建新的静止动作，可以参考现有函数模板：

```python
def custom_pose(time_sim, config):
    """自定义静止动作"""
    upper_body_targets = np.zeros(15)
    
    # 设置躯干角度
    upper_body_targets[0] = 0.0  # 躯干保持直立
    
    # 设置左臂姿态 (索引1-7)
    upper_body_targets[1] = 0.0   # 肩膀前后
    upper_body_targets[2] = 0.0   # 肩膀外展
    upper_body_targets[3] = 0.0   # 肩膀俯仰
    upper_body_targets[4] = 0.0   # 肘部
    upper_body_targets[5:8] = 0.0 # 手腕
    
    # 设置右臂姿态 (索引8-14)
    upper_body_targets[8:15] = 0.0
    
    return upper_body_targets
```

## 注意事项

1. **安全角度**: 确保所有关节角度都在安全范围内
2. **平滑过渡**: 从动态轨迹切换到静止动作时注意平滑过渡
3. **稳定性**: 静止动作应保持机器人整体平衡
4. **测试验证**: 新增动作需要在仿真环境中充分测试

## 故障排除

### 动作不自然
- 检查关节角度是否在合理范围内
- 验证左右臂的对称性设置
- 调整躯干角度以改善整体姿态

### 平衡问题
- 确保下半身policy正常工作
- 检查重心是否偏移过大
- 适当调整躯干角度

### 关节限制警告
- 降低超出限制的关节角度
- 参考实际机器人的关节限制
- 使用更保守的角度设置
